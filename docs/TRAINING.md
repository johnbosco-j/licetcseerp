# Training checklist

Run each session on the live ERP with a projector. Tick when every participant has done
the step themselves on their own account. About 45 minutes per group.

## HOD and tier 1 (once)

- [ ] Sign in, change the default password, turn on **two-step sign-in** (My Profile) and
      sign in again with the code.
- [ ] Dashboard: read today's hour-wise panel and the action centre.
- [ ] Attendance → All classes: open any hour, correct a locked hour with a reason, unlock
      an hour for 30 minutes.
- [ ] Condonation tab: approve and reject a request.
- [ ] Insights: change the term, export the class KPIs and the missing-hours list.
- [ ] Configuration: change a rule and save; edit a course's teachers and elective slot;
      open the timetable editor, split an hour between batches, use *Whole block*.
- [ ] Outcomes: open the term's programme outcome report.
- [ ] Know the recovery steps: lost phone (`scripts/reset-two-step.mjs`), forgotten
      password (User Accounts), new staff (`scripts/create-staff.mjs`).

## Class advisors

- [ ] Take any hour of your class; hand an hour over to a colleague.
- [ ] Reset a student's password and attendance phone (User Accounts / Attendance).
- [ ] Forward a condonation request; read Insights for your class.

## Faculty (every teacher)

- [ ] Sign in, change the password, check *My classes* shows your hours (tell the HOD if
      a course is missing).
- [ ] Take one hour: mark absentees, an OD, add the topic, submit; correct it within
      10 minutes; see it lock.
- [ ] Close the panel half-way and reopen it: the marks are still there (autosave).
- [ ] Self check-in: open it, start the Attendance Station on your laptop
      (`station/README.md`), let two students check in, enter the head count, submit.
- [ ] Marks: import a component from Excel, then publish it on the Outcomes page.
- [ ] Outcomes: write the COs and the CO–PO matrix of one course.

## Students (in class, 10 minutes, by the class advisor)

- [ ] Sign in and change the password.
- [ ] Attendance: read the overall %, eligibility and "hours in a row needed".
- [ ] Set the attendance PIN.
- [ ] Courses: check the right elective options are listed; give course feedback.
- [ ] Know where to object to a published mark and how to request condonation.
